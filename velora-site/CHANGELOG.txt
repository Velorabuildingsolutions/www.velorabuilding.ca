VELORA Building Solutions — Mobile Responsiveness Update
=========================================================

MOBILE ISSUES CORRECTED
- Desktop-only navigation replaced on small screens with a hamburger menu
- Multi-column layouts (hero, services, projects, process, testimonials,
  footer, quote form, contact page) previously overflowed on phones; all
  now stack to a single column
- Oversized hero (92vh, 68px headline) reduced for phones with fluid type
- Fixed-height image frames shortened on mobile (hero 380px, gallery 340px,
  before/after 300px)
- Buttons/CTAs now stack full-width on phones (easy tap targets, 44px+)
- Form inputs enforced to a 48px minimum height for touch
- Horizontal overflow eliminated at all tested widths (320-1440px)

FILES MODIFIED
- index.html, services.html, projects.html, quote.html, contact.html
  (responsive stylesheet added to each <head>, class hooks added to layout
  containers, hamburger menu + mobile menu panel added to the nav,
  menu open/close logic added to each page's component script)
- No file names, page URLs, image paths, wording, or brand styling changed

RESPONSIVE BREAKPOINTS
- <=600px   phones: single column everywhere, stacked buttons, full-width forms
- <=900px   tablets: nav collapses to hamburger; 2-col layouts become 1-col;
            fluid clamp() heading sizes
- <=1200px  small laptops: 3- and 4-column grids reduce to 2 columns
- >1200px   desktop: original design unchanged

MOBILE MENU — HOW IT WORKS
- Under 900px the desktop links hide and a bordered hamburger button
  (44x44px) appears in the header
- Tapping it opens a full-screen dark panel below the sticky header with
  large tap targets for every page link, the phone number, and a gold
  "Request a Quote" button
- The button carries aria-label="Menu" and aria-expanded, is keyboard
  accessible (focus-visible outlines are enabled site-wide), and the icon
  toggles between open/close states
- Selecting any link closes the menu

ACCESSIBILITY / MOTION
- Visible gold focus outlines on all links, buttons and form fields
- prefers-reduced-motion respected (animations and smooth-scroll disabled)

IMAGE PERFORMANCE RECOMMENDATION
- The PNGs in uploads/ are 1-2.5 MB each. For faster mobile loads, convert
  them to WebP (~80% quality) which typically cuts size by 70-85%, keep the
  same filenames or update the src attributes, and keep PNG originals as a
  fallback if desired. Total page weight would drop from ~8 MB to ~1.5 MB.
